# Chess pieces

The twelve SVGs are the Cburnett chess pieces by Colin M. L. Burnett,
extracted without artwork changes using `chess.svg.piece()` from python-chess
1.11.2. Only an SVG wrapper and output dimensions were added by that renderer.

https://python-chess.readthedocs.io/en/stable/svg.html
